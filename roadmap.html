Development stages

  • FORCE 0 — CALM

    Concept

    Deciding this was worth doing, and confirming the open-sourced codebase was usable.

    Done
  • FORCE 2 — BREEZE

    De-Flashed prototype

    Getting a bare-bones version of the client running in a modern browser, no Flash Player required.

    Done
  • FORCE 4 — MODERATE

    Core systems rebuilt

    Rooms, avatars, friends, chat, and the in-game economy running on rebuilt server code.

    Done
  • FORCE 6 — STRONG BREEZE

    Desktop browser client

    Polishing the browser client into something worth putting in front of testers. This is where the work is right now.

    In progress — you are here
  • FORCE 8 — GALE

    Community testing

    Opening the browser client up to Discord members willing to poke at rough edges and file bugs.

    Next
  • FORCE 10 — STORM

    Mobile client

    A mobile client, once the browser version is solid. Not started.

    Planned
  • FORCE 12 — FULL GALE

    Community SDK

    Tools for creators to build their own rooms, items, and games inside Second Wind.

    Planned
